## Description

De'klo is a personal finance and savings tracker designed to help users manage their money, track transactions, and monitor savings goals through a modern banking-inspired interface.

De'klo is built with an offline-first approach, allowing users to continue using the application without an internet connection. An internet connection is required to synchronize local data with the cloud database.

## Features

- Banking-inspired dashboard
- Deposit and Withdraw
- Transaction history
- Savings goals
- Recurring transactions
- Financial reports
- Financial insights
- Google Authentication
- PIN-based offline access
- Offline-first data storage
- Cloud synchronization

## Tech Stack

- React
- Vite
- Supabase
- PostgreSQL
- Dexie.js
- IndexedDB
- Tailwind CSS
